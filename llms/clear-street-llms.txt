# Clear Street Trading API Documentation and Guides

## Docs

- [Changelog](/changelog/index.md): Notable additions and changes to the Clear Street Trading API.
- [API Fundamentals](/guides/api-fundamentals/index.md): Understand response envelopes, pagination, and API error handling.
- [Instrument Data](/guides/instrument-data/index.md): Learn about instrument data, market data, financial statement, and news endpoints for research and discovery.
- [Omni AI](/guides/omni-ai/index.md): Learn to integrate with Clear Street’s financial copilot Omni AI through entitlements, threads, messages, and responses.
- [Trading](/guides/trading/index.md): Learn about trading hours, orders submission, cancellation and replacement along with different order types.
- [Trading Account Metrics](/guides/trading-account-metrics/index.md): Learn about account metrics like balance, positions, and portfolio history.
- [Watchlists](/guides/watchlists/index.md): Create, populate, review, and delete watchlists of instruments.
- [Get Started](/index.md): Set up your account, generate API keys, check balances, find instruments, and submit your first order.
- [OpenAPI Spec](/openapi-spec/index.md): The OpenAPI specification for the Clear Street Trading API, available as a raw YAML document.

Links below point to language-neutral HTTP documentation. SDK-specific docs follow the same URL structure with the language inserted after the base path: `/api/{language}/resources/...`.

Available languages: http, typescript, python, java, go, cli
